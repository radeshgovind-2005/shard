#   (FLAG exceptAll 0 / 0; true 14,506, false 3,189,004, null 315 on both sides). Bucket counts are exact and every
#   bucket's (count, σ = null) agrees: 5,535 buckets, 315 of them single-trip with a null σ, on both sides.
# - The doubles are NOT bit-identical: 3,558 of 5,535 buckets differ in the last bits of their mean or σ, so whole-row
#   exceptAll at trip level is 3,140,828 / 3,140,828 (the trips in those buckets). Max relative difference: mean
#   1.12e-14, σ 4.03e-15, all within the 1e-12 tolerance. Cause: the window accumulates a bucket's values in one pass
#   over its sorted rows; the aggregate sums per task first (partial_avg / partial_stddev) and merges the partial
#   buffers, so floating-point additions happen in a different order.
